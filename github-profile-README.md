I build complete web products end to end, from the API and database to the front end.
For the last eight years I have worked across fintech, healthcare, AI, blockchain, and
music, with teams in Indonesia and Singapore. I'm comfortable across the whole stack,
**Node.js, NestJS, and Laravel** on the back end and **React, Vue, and Next.js** on the
front. I care about clean APIs, interfaces that feel right, and work that still behaves
a year after launch.

On the side I build and run **[Mandum Rimba](https://mandumrimba.org)**, an open-source
map of Indonesia's forests and protected wildlife, plus the voice-AI products
**[Suara AI](https://suaraai.id)** (Indonesian) and **[Voicelyf](https://voicelyf.com)** (global).
